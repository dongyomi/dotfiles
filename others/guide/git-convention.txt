==================================================
              Git Commit Convention
==================================================

[ Commit Message Structure ]
  <type>: <subject>


[ Types ]
  feat     : 새로운 기능 추가
  fix      : 버그 수정
  docs     : 문서 수정
  style    : 코드 포맷팅, 세미콜론 누락 등 (코드 로직 변경 없음)
  refactor : 코드 리팩토링
  test     : 테스트 코드 추가/수정
  chore    : 빌드 태스크, 패키지 매니저, 설정 파일 수정


[ Rules ]
  1. 제목은 50자 이내로 작성합니다.
  2. 제목 끝에 마침표(.)를 붙이지 않습니다.
  3. 본문에는 '무엇을', '왜' 변경했는지 설명합니다.
